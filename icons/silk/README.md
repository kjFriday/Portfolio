# Silk originals

Six icons from the **Silk** set by Mark James (famfamfam.com/lab/icons/silk), licensed under
[Creative Commons Attribution 2.5](http://creativecommons.org/licenses/by/2.5/). The files here are
unedited; `readme.txt` is the set's own licence note and `SOURCES.tsv` pins each file's URL and SHA-256.

`tools/pixel_icons.py` turns each one into a project's `icon/` folder. The only change it makes is
enlarging the 16×16 pixels into whole-pixel blocks (nearest-neighbour), so the icons stay pixelated.
