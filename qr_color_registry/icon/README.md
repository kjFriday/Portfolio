# icon/

Generic Company QR Palette's icon, `qr-palette-16.png`, is a 16×16 pixel QR glyph drawn for this project (self-authored,
AGPL-3.0 like the code): QR Studio's glyph with its data modules in Color Voats' tile colors. The other sizes are
enlarged by whole pixels (nearest-neighbour) with the `outputs()` function of `tools/pixel_icons.py` in the portfolio
repo, so every size stays pixelated.
