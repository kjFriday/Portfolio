# icon/

Generic Company Color Voats' icon, `tiles-16.png`, is a 16×16 pixel glyph of nine color tiles drawn for this
project (self-authored, AGPL-3.0 like the code). The other sizes are enlarged by whole pixels (nearest-neighbour)
with the `outputs()` function of `tools/pixel_icons.py` in the portfolio repo, so every size stays pixelated.
